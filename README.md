# DevConf Landing Page - Assignment 01

**Static landing page for a developer conference, built with HTML and CSS (Programming Hero Assignment 01).**

[![Live Demo](https://img.shields.io/badge/Live_Demo-jotika--meaw.github.io-blue)](https://jotika-meaw.github.io/PH-Assignment-01/)

## About

A conference landing page for **DevConf** with a hero banner, speaker lineup, registration call-to-action, and a "Why Attend" section. Built as a pure HTML/CSS exercise with no frameworks.

## Features

- **Hero banner** with event headline
- **Meet the Speakers** - speaker cards
- **Secure Your Spot** - registration call-to-action
- **Why Attend DevConf?** - benefits section
- **Responsive layout**

## Tech Stack

- HTML5
- CSS3

## Run Locally

```bash
git clone https://github.com/jotika-meaw/PH-Assignment-01.git
cd PH-Assignment-01
```

Open `index.html` in your browser, or serve it locally:

```bash
npx serve .
```
